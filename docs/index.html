Features

필요한 건 다 있고, 설치할 드라이버는 없습니다

macOS에 내장된 오디오 기능만 사용합니다. BlackHole·Soundflower 같은 가상 오디오 장치를 따로 설치할 필요가 없습니다.

앱별 볼륨

소리를 내는 앱을 자동으로 찾아 각각 0–100%(옵션 최대 200%)로 조절합니다. 음소거, 레벨 미터, 앱별 설정 기억까지.

  • 헬퍼 프로세스는 상위 앱으로 묶어서 표시
  • 우클릭으로 특정 앱 처리 제외

입·출력 장치 제어

출력·입력 장치 전환과 하드웨어 볼륨·음소거. HDMI처럼 하드웨어 볼륨이 없는 장치는 소프트웨어 볼륨으로 대신합니다.

그래픽 · 파라메트릭 EQ

10밴드 그래픽 EQ(±12 dB)와 최대 32개 파라메트릭 필터(PK·LSC·HSC·LP·HP·NO). 주파수 응답 곡선을 보며 드래그로 편집합니다.

AutoEQ 헤드폰 보정

AutoEQ 데이터베이스의 약 8,800개 헤드폰·이어폰 프로필을 앱 안에서 검색해 바로 적용합니다. ParametricEQ.txt 가져오기/내보내기 지원.

프리셋 & 장치별 자동 전환

기본 프리셋 17종과 사용자 프리셋. 이어폰을 꽂으면 그 장치에 지정한 EQ로 자동 전환됩니다.

음질 보호

EQ 부스트만큼 자동으로 낮추는 프리앰프, 피크 리미터, 하드 클립 보호, L/R 밸런스로 소리가 깨지지 않게 지킵니다.

How it works

소리가 지나가는 길

원본 앱의 출력은 탭이 살아 있는 동안에만 음소거됩니다. 앱을 끄거나 비정상 종료돼도 시스템이 탭을 거둬 모든 소리가 즉시 원래대로 돌아옵니다.

클릭 노이즈 없음재생 중에 EQ를 바꿔도 "틱" 소리 없이 부드럽게 전환됩니다.
자가 복구출력 장치를 바꾸거나 잠자기에서 깨어나도 스스로 다시 연결됩니다.
녹음하지 않음오디오는 실시간으로 처리만 되고 저장되거나 전송되지 않습니다.
Install

설치하기

Apple 공증(Notarization)을 받지 않은 개인 배포 앱이라, 처음 한 번은 macOS의 보안 확인을 직접 통과시켜야 합니다.

내려받아 응용 프로그램 폴더로 옮기기

Releases 페이지에서 AudioMixer.zip을 받아 압축을 풀고, AudioMixer.app을 응용 프로그램 폴더로 드래그합니다.

처음 실행 허용하기

앱을 열면 "확인되지 않은 개발자" 경고가 뜹니다. 완료를 누른 뒤 시스템 설정 › 개인정보 보호 및 보안 아래쪽의 그래도 열기를 클릭하고 암호를 입력하세요.

터미널이 편하다면 아래 명령 한 줄로도 됩니다.

xattr -dr com.apple.quarantine /Applications/AudioMixer.app

시스템 오디오 녹음 권한 허용

메뉴 막대에 페이더 아이콘이 나타나고, 앱이 처음 소리를 처리할 때 권한을 요청합니다. 허용을 누르세요.

놓쳤다면 시스템 설정 › 개인정보 보호 및 보안 › 화면 및 시스템 오디오 녹음에서 Audio Mixer를 켜면 됩니다.

(선택) 로그인 시 자동 실행

메뉴 막대 아이콘 › 설정 탭에서 "로그인 시 실행"을 켜 두면 재부팅 후에도 바로 쓸 수 있습니다.

권한을 거부해도 소리는 정상입니다. 이 경우 장치 볼륨 제어만 가능하고, 앱별 볼륨·EQ는 동작하지 않습니다.
FAQ

자주 묻는 질문

왜 "시스템 오디오 녹음" 권한이 필요한가요?

다른 앱의 소리에 볼륨·EQ를 적용하려면 그 소리를 받아 처리해야 하는데, macOS는 이 기능을 "시스템 오디오 녹음" 권한으로 묶어 두었습니다. Audio Mixer는 오디오를 실시간으로 처리만 하며 파일로 저장하거나 외부로 보내지 않습니다.

앱을 강제 종료하면 소리가 안 나오지 않나요?

아닙니다. 탭은 Audio Mixer 전용이라, 앱이 꺼지는 순간 시스템이 탭을 제거하고 모든 앱의 소리가 원래 경로로 즉시 돌아옵니다.

DAW나 오디오 인터페이스를 쓰는데 간섭하지 않나요?

현재 기본 출력 장치가 아닌 다른 장치로 직접 출력하는 앱(예: 오디오 인터페이스를 쓰는 DAW)은 건드리지 않습니다. 필요하면 믹서 탭에서 앱을 우클릭해 처리에서 제외할 수도 있습니다.

재생 시작 직후 잠깐 원래 소리가 들려요.

앱이 재생을 시작한 뒤 탭이 연결되기까지 아주 짧은 순간이 있어, 그 사이에는 처리 전 소리가 날 수 있습니다. 정상 동작입니다.

업데이트 후 권한을 다시 물어봐요.

공증받지 않은 개인 배포 앱은 새 버전마다 서명이 달라져 macOS가 다른 앱으로 인식할 수 있습니다. 권한 설정에서 기존 항목을 지우고 다시 허용해 주세요.
